# Objective

Create a reusable React component with TypeScript props, accessible markup, and documented usage.

# Requirements

- Define prop types and sensible defaults
- Support keyboard and screen reader use cases
- Include a minimal usage example

# Acceptance Criteria

- [ ] Component renders in isolation
- [ ] Props are fully typed
- [ ] Focus and aria attributes verified
