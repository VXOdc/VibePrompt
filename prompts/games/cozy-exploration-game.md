# Game premise

Build a small, complete exploration game set in [a forgotten greenhouse, rooftop garden, or other setting]. The player is [character] returning to a place connected to [memory or mystery]. Discovery and atmosphere are the reward; combat and timers are not part of the design.

# Play loop

- Move through a compact connected environment and inspect objects.
- Find notes, seeds, and small environmental changes that reveal the story.
- Use collected objects in a few understandable interactions.
- Let the world reflect the player's discoveries and reach a satisfying ending.

# Feel and presentation

Choose a consistent visual style and a small palette inspired by the setting. Use deliberate sound and motion cues that remain comfortable and respect reduced-motion settings. Make the environment readable, navigation forgiving, and interaction feedback clear.

# Technical requirements

- Support keyboard controls and touch controls with visible instructions.
- Keep game state understandable and persist progress locally when practical.
- Include pause, restart, sound, and reduced-motion controls.
- Use an existing game library when it fits the chosen platform.

# Acceptance criteria

- The opening explains the controls and objective.
- Every key interaction can be completed with the supported controls.
- A first-time player can reach the ending without external instructions.
