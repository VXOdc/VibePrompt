# Objective

Refactor the specified modules to reduce coupling and clarify boundaries.

# Requirements

- List modules in scope
- Preserve public APIs unless explicitly approved to change
- Add or update tests for touched behavior

# Acceptance Criteria

- [ ] Behavior unchanged (or changes documented)
- [ ] Smaller functions/modules with clear names
