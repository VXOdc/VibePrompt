# Concept

Create an interactive field guide to [planet name or defining idea]. The audience is curious explorers. The experience should feel like a scientific notebook kept by someone who has just returned from the planet.

# Entries

Create a coherent starter set of fictional organisms and places. For every entry include a name, visual description, habitat, scale, behavior, one surprising fact, and a note about how an explorer should observe it. Keep details consistent with the planet's climate and ecology.

# Interaction and art direction

Let visitors browse by habitat and discover one entry at random. Build a legible entry view with a strong illustration or original visual treatment, clear labels, and short field notes. Use a restrained palette inspired by the planet's environment, a consistent editorial grid, and subtle transitions that support exploration.

# Quality requirements

- Make filters, navigation, and random discovery keyboard accessible.
- Design for mobile and desktop, with readable text and descriptive image alternatives.
- Provide working empty and no-results states.
- Keep the fictional science clearly framed as worldbuilding rather than real-world advice.

# Acceptance criteria

- Visitors can browse and filter entries without losing their place.
- Each entry feels part of the same believable ecosystem.
- The visual design makes the imaginary world memorable and the information easy to scan.
