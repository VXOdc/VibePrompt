# Objective

Create a friendly digital guide for [market name] in [neighborhood]. Help visitors decide when to go, find the stalls they care about, and plan a comfortable visit.

# Features

- Show date, hours, address, transit, accessibility details, and weather guidance supplied by the organizer.
- Browse vendors by food, craft, music, and other relevant categories.
- Give each vendor a compact profile with description, price range, dietary details when provided, and location within the market.
- Offer a simple map or numbered stall layout with a list alternative.
- Make event updates easy for the organizer to edit.

# Design direction

Create an energetic night-market atmosphere through typography, color, and real vendor photography while keeping all practical details easy to scan. Use a strong mobile-first layout for visitors who are already at the event. Keep contrast high and controls large enough to tap.

# Acceptance criteria

- A visitor can find the event time and location immediately.
- Vendor categories, profiles, and map/list navigation work on a phone.
- Unknown event details are not invented; the interface shows a clear unavailable state.
