# Objective

Build a portfolio for [name or discipline] that helps [intended audience] understand the creator's strengths and start a conversation.

# Content

Include a direct introduction, selected work, the creator's role and contribution on each project, a concise process or biography, and a working contact path. Use the supplied project descriptions and media. When examples are missing, use clearly labeled sample content that is easy to replace; do not invent client endorsements or career claims.

# Art direction

Choose a visual concept that reflects [creator's personality, references, or medium]. Make the work itself the focus. Use a consistent grid and type system, generous readable spacing, and restrained transitions. Give each project enough context to be understood without opening a separate page.

# Build requirements

- Create a responsive navigation and project browsing experience.
- Provide descriptive alternative text and keyboard-accessible galleries.
- Ensure all contact and social links point to supplied destinations.
- Include a page title and social sharing metadata.

# Acceptance criteria

- A new visitor can identify who the creator is, what they do, and how to contact them.
- Project details stay readable and aligned from phone to desktop.
- No decorative controls imply an interaction that does not exist.
