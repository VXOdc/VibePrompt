# Objective

Create a playful worldbuilding tool that generates a compact imaginary place from a few user choices or a single surprise action.

# Generated world

Each result includes a place name, a vivid sensory detail, a local custom, a person visitors might meet, and one open mystery. Keep every detail internally consistent and specific. Offer a few genre and mood controls without turning setup into a long form.

# Interaction

- Let visitors generate another world, save a favorite locally, and copy a result.
- Keep the result stable while the visitor reads or copies it.
- Make controls usable with keyboard and screen reader.
- Provide an inviting empty state before the first result.

# Art direction

Create the feeling of opening a small travel notebook. Use distinct typography, a restrained palette, and a small visual detail that supports the world. Keep the generated text as the focus.

# Acceptance criteria

- Every action has a visible result.
- Generated details feel varied but belong to one coherent place.
- Saved worlds remain available after a page refresh when local storage is supported.
