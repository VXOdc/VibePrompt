# Project

Design and build a polished landing page for [product or service]. Its audience is [audience], and its main purpose is [primary action].

# Creative direction

Create a visual identity that feels specific to the product and avoids familiar template patterns. Use [brand colors or reference] as the palette direction. Establish a consistent spacing rhythm, a readable type scale, clear contrast, and a distinctive but restrained composition. Use real interface or product imagery that helps visitors understand what is offered.

# Page structure

- A concise header with the brand, essential navigation, and one clear action
- A first viewport that identifies the product, audience, and value immediately
- A product demonstration or visual that shows the experience in context
- Benefits connected to real user needs, with specific supporting details
- A straightforward explanation of how it works, pricing, or next steps as appropriate
- A final action and a complete footer with working links

# Quality requirements

- Make the layout adapt cleanly from narrow phones to large desktop screens.
- Make every control work with keyboard and pointer input, with visible focus states and accessible names.
- Use meaningful content instead of filler, fake metrics, or invented testimonials.
- Include a page title, meta description, and social sharing metadata.
- Provide a useful loading, empty, or error state for any dynamic content.

# Acceptance criteria

- Visitors can explain the product and find the main action from the first screen.
- The page feels visually coherent and tailored to its subject.
- Navigation and actions work at mobile and desktop sizes.
